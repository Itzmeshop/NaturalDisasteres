# 🌳 Nature Guardian

Nature Guardian — это браузерная игра на **Phaser 3**, в которой игрок восстанавливает природу после стихийных бедствий.

---

## 🎮 Особенности

- 🌍 Процедурная генерация мира
- 🌳 Рост и гибель деревьев
- 🦌 Животные с простым ИИ
- 🌦 Динамическая погода
- 🔥 Лесные пожары
- 🌊 Наводнения
- 🌪 Торнадо
- ☀ Засуха
- 🌸 Смена времён года
- 🌞 День и ночь
- 🏆 Система достижений
- 💾 Сохранения
- 🎵 Музыка и звуки

---

## 🚀 Запуск проекта

Установить зависимости

```bash
npm install
```

Запустить игру

```bash
npm run dev
```

Собрать релиз

```bash
npm run build
```
